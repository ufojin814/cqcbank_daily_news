# 重庆地区城商行理财产品对比分析项目

> 面向重庆银行总行个人部财富管理平台，对重庆地区主要城商行代销理财产品进行系统性对比分析。

## 项目简介

本项目基于普益标准全量表数据，对重庆地区10家目标银行（重庆银行、重庆农商行、重庆三峡银行、重庆富民银行、成都银行、汉口银行、厦门银行、哈尔滨银行、广东南粤银行、大连银行）代销的理财产品进行整理、匹配和对比分析，输出产品总表和三张分类分表。

## 快速开始

### 1. 环境依赖

```bash
pip install pandas openpyxl xlrd numpy
```

- Python 3.9 ~ 3.11
- pandas（数据处理）
- openpyxl（Excel读写）
- xlrd（旧版.xls读取）
- numpy（数值计算）

### 2. 数据源准备

每次分析需要用户提供：
- **全量表Excel**（通常2个文件）：普益标准导出的全市场理财产品数据，文件名如 `银行理财产品查询 (6).xlsx`、`银行理财产品查询 (7).xlsx`
- **重庆银行在售清单**：用户提供的重庆银行当期代销理财产品清单，如 `代销理财当前在售清单（2026.9.24）.xlsx`

### 3. 执行分析

**默认方案（方案四）**：用户发Excel文件 + 说"开始分析" → 自动执行

```bash
# 第一步：匹配重庆银行产品（需先修改脚本中的文件路径）
python scripts/match_cqb.py

# 第二步：生成总表+三张分表（需先修改脚本中的文件路径）
python scripts/run_plan2.py
```

### 4. 输出产物

- **产品总表**：全量字段，包含所有目标银行代销产品
- **三张分表**（同一个Excel的三个Sheet）：
  - Sheet1：重庆银行产品（按用户在售清单匹配）
  - Sheet2：重庆本土银行产品（三峡银行、重庆农商行、富民银行）
  - Sheet3：其他城商行代销产品（成都、汉口、厦门、哈尔滨、南粤、大连）

## 核心逻辑（方案四）

1. **重庆银行产品**：按用户提供的在售清单，通过三级匹配（代码精确→标准化名称→token交叉匹配）在全量表中查找，**不按全量表代销机构字段筛选**
2. **表2本土银行**：重庆三峡银行+重庆农村商业银行+重庆富民银行自营及代销（含渝农商理财自营），排除重庆银行
3. **表3其他城商行**：成都银行+汉口银行+厦门银行+哈尔滨银行+广东南粤银行+大连银行代销，排除重庆银行
4. **母份额筛选**：表2表3仅保留母份额（分级份额类型为空或"总份额"）；兜底：无母份额只有子份额时取A类（代码末尾为A）或第一个子份额
5. **多代销机构展开**：一只产品被多家目标银行代销时，每家银行各占一行
6. **标红规则**：同产品类型下，业绩比较基准中枢和下限均高于重庆银行该类型最高代表产品的行，整行标红

## 关键注意事项

- **分析前必须检查**：用户当次是否上传了全量表Excel，未上传时必须提醒
- **全量表业绩基准字段**：字段名随导出窗口变化，如 `业绩比较基准（2026-10-01至2026-10-08）`，执行前需确认字段名
- **现金管理类产品**：不设固定业绩比较基准，该字段为空属正常现象
- **空行过滤**：全量表中存在产品名称为空的脏记录，匹配前必须过滤
